# Mini E-Learning System

## Description
A Java-based desktop e-learning application developed using JavaFX and MySQL.

## Features
- User Login & Signup
- Dashboard Interface
- Quiz Management
- Database Connectivity
- Interactive GUI

## Technologies Used
- Java
- JavaFX
- JDBC
- MySQL

## Concepts Used
- Object-Oriented Programming (OOP)
- Event Handling
- Database Management
- GUI Development

## Future Improvements
- Better UI/UX
- Admin Panel
- Progress Tracking
- Online Course Management
